# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

This is a demonstration repository showcasing secure authorization patterns.

## Security Features Implemented

### Authentication

- JWT tokens with configurable expiration
- Passport.js integration
- Secure password hashing with bcrypt

### Authorization

- Custom NestJS Guards for ownership verification
- Role-based access control decorator
- Centralized authorization logic

### Data Protection

- DTO validation with class-validator
- TypeORM parameterized queries
- Helmet security headers

### Best Practices

- Dependency injection for testability
- Exception filters for consistent error handling
- Request logging and audit trails

## Contact

For security concerns, please open an issue.
